# Cisco IOS Network Engineering Demonstrations

- [Cisco 7606-S Core Router](./7606s/)

This section presents my hands-on Cisco routing and switching examples. The material focuses on design decisions, configuration structure, and operational practices. Public files use fictional identifiers and documentation-only addressing.

The 7606-S example covers multi-VRF service separation, 802.1Q subinterfaces, static EtherChannel, BGP IPv4/IPv6, route-maps, PBR, QoS policing, PVST, and management controls.

These are reduced technical demonstrations, not original device backups or deployment-ready configurations. Review each platform note and validate commands against the exact hardware and software release before lab use.
