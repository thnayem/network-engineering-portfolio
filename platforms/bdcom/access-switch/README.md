# BDCOM Access Switch Reference

Source software: 2.1.1B build 28530. Exact hardware model is not stated in the source export.

The reference documents a 28-port Gigabit Ethernet configuration with RSTP priority 4096, individual access/service VLAN handoffs using allowed VLAN + untagged VLAN + PVID, selected trunk ports, root guard, and static port aggregation on GigaEthernet0/27-0/28.

Management addressing is replaced with documentation-only prefixes. Hostname, human/site labels, credentials and SNMP community are removed. The example is curated and has not been validated on hardware.

See [sanitized configuration](./bdcom-access-switch-reference.cfg.example).
