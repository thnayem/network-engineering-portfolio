# Cisco IOS / IOS XE Network Engineering Examples

- [Cisco 7606-S Core Router](./7606s/)
- [Cisco ASR 920-24SZ-M](./asr920/)

This section presents hands-on Cisco routing and switching examples. The material focuses on design decisions, configuration structure, and operational practices. Public files use fictional identifiers and documentation-only addressing.

The 7606-S example covers multi-VRF service separation, 802.1Q subinterfaces, static EtherChannel, BGP IPv4/IPv6, route-maps, PBR, QoS policing, PVST, and management controls.

The ASR920 example covers Ethernet service instances (EVC), bridge domains, BDI-based routed services, multi-VRF BGP, prefix-lists, route-maps, BGP communities, and QoS policing.

These are reduced technical demonstrations, not original device backups or deployment-ready configurations. Review each platform note and validate commands against the exact hardware and software release before lab use.
